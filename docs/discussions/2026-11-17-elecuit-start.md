# elecuit 시작

## 질문

- 전기전자 전공자가 GPT 같은 LLM에게 회로를 물으면 그림이 자주 틀린다. 틀리지 않게 하는 조작 가능한 템플릿을 만들 수 있는가.
- 화면 안의 모든 표시는 KaTeX를 지원해야 한다.

## 확인한 사실

- 사용자가 보여 준 LLM 그림(1-3 domino 게이트에 X precharge 추가)에서 `Y` 가로선이 precharge PMOS의 VDD 세로선에 닿아 `Y`가 VDD에 단락되어 있었다.
- 원인은 LLM이 좌표를 직접 찍는 데 있다. 좌표만으로는 "선이 지나간다"와 "선이 연결된다"가 구분되지 않는다.
- CircuitikZ와 schemdraw는 배치를 LLM이 정하므로 같은 종류의 실수를 막지 못한다. schemdraw 라벨은 KaTeX가 아니다.

## 결정

1. LLM은 좌표 없이 소자와 노드 이름만 쓰는 netlist를 낸다. 연결은 노드 이름이 같은지로만 정한다.
2. 렌더러가 배치를 계산한다. VDD–GND 사이를 직렬·병렬로 분해해 스택으로 그리고, 선은 기하적으로 겹치지 않음이 보장되는 곳에만 긋고 나머지는 노드 이름 라벨로 잇는다.
3. 첫 범위는 CMOS 트랜지스터 회로(`nmos`, `pmos`), 논리 게이트 기호(`inv`, `buf`, `nand`, `nor`, `and`, `or`), `cap`이다.
4. 화면은 붙여 넣는 단일 웹 페이지이고, 편집은 텍스트와 실시간 미리보기로 한다.
5. 사용자 요청으로 이 프로젝트는 하우스 디자인 스타일과 시안 승인 절차를 쓰지 않고, 에이전트가 고른 디자인으로 만든다.
6. 브라우저 전용 Vite 앱을 하나의 HTML 파일로 빌드해, 설치 없이 열 수 있게 한다.

## 2026-11-17 채팅 안 미리보기

### 질문

- 붙여 넣기 대신, GPT가 답할 때 HTML 미리보기로 회로도를 바로 띄울 수 있는가. HTML 소스에 데이터만 주입하는 방식이면 되는가.

### 확인한 사실

- ChatGPT의 Canvas 미리보기는 GPT가 직접 쓴 HTML만 보여 주므로, 1.8MB 단일 HTML에 데이터만 바꿔 넣는 방식은 쓸 수 없다.
- 사용자가 ChatGPT Canvas에서 jsdelivr의 KaTeX 스크립트와 스타일을 불러오는 HTML을 시험했고, 수식이 정상으로 보였다. Canvas는 외부 CDN 스크립트를 실행한다.
- npm에 `elecuit`이라는 패키지 이름은 비어 있다.

### 결정

1. 렌더러를 스크립트 하나(`dist/elecuit.js`)로 묶는다. 호스트 페이지의 `<script type="text/elecuit">` 블록마다 회로도, 검사 결과, 노드 연결 정보를 그린다.
2. netlist는 `<script type="text/elecuit">` 블록에 둔다. 수식의 `<` 같은 글자가 HTML로 해석되지 않게 하기 위해서다.
3. KaTeX 스타일과 글꼴은 번들에 넣지 않고 jsdelivr에서 번들의 KaTeX와 같은 버전으로 불러온다.
4. GPT는 짧은 템플릿에서 netlist 블록만 바꿔 쓴다. 지침 문구는 `canvasPrompt`가 만든다.

### 보류

- 번들을 올릴 곳(npm 공개 패키지 등)과, 그 URL을 넣은 지침 복사 버튼.
