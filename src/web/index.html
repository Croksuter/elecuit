elecuit netlist를 회로도로
    문법
    nmos pmos
    이름 g=게이트 d=드레인 s=소스
    inv buf
    이름 in=A out=Z
    nand nor and or
    이름 in=A,B out=Z
    cap
    이름 a=Y b=GND value=$C_L$
    input output
    A B … 외부 단자
    label
    phi $\phi$ 노드의 표시 이름 (KaTeX)

    VDD·GND는 예약된 이름이고, 같은 이름의 노드끼리만 연결됩니다.

    입력은 이 브라우저에만 저장됩니다.

    netlist를 넣으면 여기에 회로도가 그려집니다.

    노드에 마우스를 올리면 연결된 단자가 보입니다.
